## 🔬 Философия и дизайн-система BIOCODE

BIOCODE — это уникальный визуальный язык на стыке органической биологии и футуристической инженерии:
- **Глобальная дискретная сетка**: вся вёрстка строго подчинена модульной сетке, делящейся на базовые ячейки и собираемой в полимино-контейнеры сложной конфигурации (L-Shape, U-Shape, многомодульные составные плашки).
- **Векторный движок галтелей (`BiocodeFilletPath`)**: расчет сопряжений с выпуклыми (+90°) и вогнутыми (-90°) галтелями с кривыми Безье $C^1$, обеспечивающими идеальную 1px резкость границ.
- **Аппаратное слияние (GPU MetaBall)**: двухслойная архитектура с аппаратным слиянием силуэтов на базе `RenderEffect.createChainEffect` (Gaussian Blur + ColorMatrix threshold) без замыливания контента.
- **Телеметрическая шкала «Био-заряд»**: 28-сегментный LED-индикатор калорий с градиентной подсветкой ячеек, световым импульсным курсором и адаптивной сменой оттенка при превышении нормы.
- **Точечно-матричные дисплеи 5×7 (`BiocodeDotMatrix`)**: растровые цифровые индикаторы показателей и калорийности.
- **Трёхуровневая адаптивность плашек еды**: карточки автоматически подстраивают форму контура и высоту (Single-line 52dp, Double-line 76dp, Triple-line 98dp) под длину названия, динамически сжимая расстояние между компактными элементами.

## 🎨 Мульти-темовый движок и радиальная био-волна

В приложение встроен динамический движок из 5 цветовых схем, переключаемых по нажатию на звезду в бороздке Metabolic Hub:

1. **`01` NOGUCHI MOSS** *(Базовая)*: Био-лайм `#9FD700`, хвойный мох `#272C1A`, пинеаль `#446158` и крем `#FFFEEF`.
2. **`02` CYBER PINK**: Неоновый пинк `#FF096C`, темный графит `#192731`, сланцевый `#2A3843` и маджента `#F2088A`.
3. **`03` CRIMSON NAVY**: Алый кримсон `#E6223A`, бездонный нейви `#03213D`, индиго `#062A48` и бордо `#690722`.
4. **`04` FIG CHARTREUSE**: Электрический шартрез `#B6C648`, ежевичный `#260729`, инжирный баклажан `#543A55` и фисташка `#DFE6B0`.
5. **`05` NORDIC CYAN**: Сияющее золото `#F7C800`, изумрудный циан `#039692`, угольный `#121819` и березовый шпон `#F9E7D2`.

**Эффекты переключения**:
- **Shockwave Wave Overlay**: 3-слойная радиальная био-ударная волна с радиальным градиентом, расходящаяся прямо из центра кнопки со звездой.
- **450ms Color Morphing**: одновременная плавная интерполяция всех 21 цветовых токенов палитры без скачков и лагов.
- **Кинетическая звезда**: поворот на 360° с пружинным эффектом отскока (`spring`).
- **Телеметрический HUD-бейдж**: плавно всплывающая верхняя капсула с кодом и описанием активированной темы.

## 🛠 Сборка и запуск

### Требования
- **JDK**: 17 или 21 (например, Android Studio JBR)
- **Android SDK**: `minSdk = 31` (Android 12+ для поддержки аппаратно-ускоренных RenderEffect) / `targetSdk = 34`
- **Gradle**: 8.x / 9.x

### Сборка Debug APK
```bash
./gradlew assembleDebug
```
Готовый APK будет сгенерирован по пути:
`app/build/outputs/apk/debug/app-debug.apk`

### Установка на подключенное устройство
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.biocode.app/.MainActivity
```
